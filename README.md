# 💰 Cashier Programs - KuahKuwi

Aplikasi Sistem Kasir berbasis Visual Basic .NET untuk mengelola transaksi penjualan dan manajemen inventory di restoran atau warung makan "KuahKuwi".

## 📋 Deskripsi Proyek

Proyek ini merupakan tugas akhir (UAS) dari Kelompok 3 untuk mata kuliah Pemrograman Desktop. Aplikasi ini dirancang sebagai solusi sistem kasir yang komprehensif dengan fitur-fitur pengelolaan penjualan dan inventory yang profesional.

## 🎯 Fitur Utama

- ✅ **Manajemen Transaksi Penjualan** - Input dan proses transaksi kasir secara real-time
- ✅ **Manajemen Inventory** - Kelola stok produk dan informasi menu
- ✅ **Laporan Penjualan** - Generate laporan harian, mingguan, dan bulanan
- ✅ **Crystal Report** - Fitur reporting profesional dengan formatting dan export yang fleksibel
- ✅ **Manajemen Pengguna** - Sistem login dan hak akses pengguna
- ✅ **Database Integration** - Penyimpanan data terstruktur dan aman
- ✅ **User Interface yang Ramah** - Interface desktop yang intuitif dan mudah digunakan

## 💻 Teknologi yang Digunakan

- **Bahasa Pemrograman:** Visual Basic .NET
- **Platform:** Windows Desktop Application
- **Database:** SQL Server / Access Database
- **IDE:** Visual Studio
- **Reporting Tool:** Crystal Reports

## 🚀 Cara Menjalankan

### Prasyarat

- Visual Studio 2019 atau lebih baru
- .NET Framework 4.7.2 atau lebih baru
- SQL Server Express (atau database sesuai konfigurasi)
- Crystal Reports for Visual Studio (untuk mengembangkan report)

### Langkah Instalasi

1. **Clone Repository**
   ```bash
   git clone https://github.com/77ferdian/Cashier-Programs-KuahKuwi.git
   cd Cashier-Programs-KuahKuwi
   ```

2. **Buka Solution**
   - Buka file `UAS_PEMDES_KEL3.sln` dengan Visual Studio

3. **Konfigurasi Database**
   - Update connection string di konfigurasi proyek
   - Jalankan script database jika tersedia

4. **Install Crystal Reports Runtime** (jika diperlukan)
   - Download dan install Crystal Reports Runtime untuk .NET
   - Pastikan dependency terpenuhi

5. **Build dan Run**
   - Build solution (Ctrl + Shift + B)
   - Run aplikasi (F5 atau Debug → Start Debugging)

## 📊 Fitur Crystal Report

Aplikasi ini mengintegrasikan **Crystal Reports** untuk menghasilkan laporan yang profesional dan dapat di-customize:

- 📈 **Laporan Penjualan Harian** - Ringkasan transaksi harian dengan detail produk dan total
- 📅 **Laporan Periode** - Laporan penjualan mingguan dan bulanan
- 📦 **Laporan Inventory** - Status stok barang dan rekomendasi pembelian
- 💾 **Export Format** - Export ke PDF, Excel, Word, dan format lainnya
- 🖨️ **Print Ready** - Desain report yang siap untuk dicetak

Semua report template disimpan di folder `Reports/` dan dapat dimodifikasi menggunakan Crystal Reports Designer.
